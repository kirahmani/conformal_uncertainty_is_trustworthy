# Conformal Uncertainty Under Operational Phase Transitions

Experiment code for:  
**"Operational Phase Determines Whether Conformal Uncertainty Is Trustworthy
in Machine Learning-Based Anomaly Detection for Microservices"**  
(Scientific Reports)

## Reproduce

```bash
pip install -r requirements.txt
cd src
python3 experiment.py        # synthetic matrix, ~10 min -> results/
python3 realdata.py          # real RCAEval telemetry -> results/
python3 analysis_final.py    # tables + figures
```

Seeds 1–10, deterministic. PyTorch needed for the neural detectors;
without it the study runs on PCA and Isolation Forest.

## Layout

- `src/phases.py` — six-phase operational model, synthetic telemetry generator
- `src/detectors.py` — PCA, Isolation Forest
- `src/neural.py` — dense autoencoder, LSTM sequence autoencoder (PyTorch)
- `src/conformal.py` — split, rolling, frozen-rolling, ACI, Mondrian; online regime detector
- `src/experiment.py` — synthetic matrix: 4 detectors × 2 calibration regimes × 10 seeds
- `src/realdata.py` — RCAEval replication with block-bootstrap inference
- `src/analysis_final.py` — tables, paired tests with Holm correction, figures
- `results/` — pre-computed CSVs for all manuscript tables
- `figures/` — manuscript figures (regenerated by `analysis_final.py`)
- `data/rcaeval_multisource/` — RCAEval real telemetry subset;
  only `metrics.csv` and `inject_time.txt` are used.
  Full dataset: https://github.com/phamquiluan/RCAEval/releases

## Note

Three defects in an earlier version were corrected during preparation

denominator, cross-detector pooling. Results predating those fixes
